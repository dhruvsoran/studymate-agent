# 📌 **Overview**

**StudyMate** is an AI-powered **Study Scheduler & Learning Coach** designed to help students generate structured Pomodoro-style study plans, adapt when sessions are missed, and evaluate learning workloads.

This project is built for the **Kaggle Agents Intensive Capstone – Concierge Agents Track**, and demonstrates a complete agent pipeline:

✔ Planning
✔ Memory
✔ Adaptive rescheduling
✔ Evaluation
✔ Observability
✔ Cloud deployment

The entire agent system is available both inside a **Kaggle notebook** and as a **live FastAPI backend**.

---

# 🚀 **Features**

### 🧮 **1. Study Planner Agent**

* Generates Pomodoro-style blocks (25 min study / 5 min break)
* Distributes topics over available days
* Uses preferred study time windows

### 🔄 **2. Adaptive Replanner**

When a session is missed:

* The block is removed
* Re-added at the end of the schedule

### 💾 **3. In-Memory User Preferences**

Stores lightweight preferences such as:

* Preferred study window
* Weak topics
* Topic rotation

### 📊 **4. Evaluation Engine**

Runs 80+ synthetic user simulations to analyze:

* Topic coverage
* Workload fairness
* Latency performance

### 📝 **5. Interactive Notebook UI**

Built with **ipywidgets** for real-time input collection and plan visualization.

### ☁️ **6. API Deployment (FastAPI + Render)**

Live endpoints:

* **`GET /ping`** – health check
* **`POST /plan`** – generate a study plan
* **`POST /adapt`** – replan after missing a block

## **🧮 2. Generate Study Plan**

### **POST /plan**

**Body:**

```json
{
  "user_id": "demo1",
  "goal": "Revise DSA",
  "deadline_str": "2025-11-25",
  "hours_per_day": 2,
  "topics": ["Graphs", "Trees", "DP"],
  "preferred_times": "18:00-21:00"
}
```

**Response:**

* Full generated schedule (list of blocks)

---

## **🔄 3. Adapt After Missed Session**

### **POST /adapt**

**Body:**

```json
{
  "user_id": "demo1",
  "plan": [ ... ],
  "miss_index": 0
}
```

**Response:**

* Updated schedule with the missed block moved to the end

# ☁️ **Deployment Instructions**

The project is deployed on **Render** using FastAPI.

To deploy your own version:

### **1. Clone the repository**

```bash
git clone https://github.com/your-username/studymate-agent.git
cd studymate-agent
```

### **2. Install dependencies**

```bash
pip install -r requirements.txt
```

### **3. Run locally**

```bash
uvicorn main:app --reload
```

### **4. Deploy to Render**

* Create new Web Service
* Connect GitHub repo
* Runtime: Python
* Build Command:

```
pip install -r requirements.txt
```

* Start Command:

```
uvicorn main:app --host 0.0.0.0 --port 8000
```
